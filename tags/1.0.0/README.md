# Calamity Vein v1.0.0 (Beta) — ผลึกวิบัติ รุ่นเบต้าแรก

## 🇹🇭 ภาษาไทย — รุ่นเบต้า

**Calamity Vein — ผลึกวิบัติ** เกมแอ็กชันเลื่อนข้างแบบร่วมทีม 1–6 คน ในโลกหลังภัยพิบัติที่ผลึกคือเทคโนโลยี และทุกครั้งที่ใช้พลังต้องจ่ายราคา

### มีอะไรในรุ่นนี้
- **ต่อสู้แบบอ่านจังหวะ** — ตีเบาต่อเนื่อง ปิดด้วยตีหนัก · บล็อกลดดาเมจ · กดบล็อกให้ตรงจังหวะ = แพร์รี ไม่เสียเลือดและทำให้ศัตรูเสียหลักจนล้ม · dash หลบ
- **ไม่มีอาชีพ** — เลือกหน้าตาตัวละคร 1 ใน 4 แบบ แล้วถืออาวุธอะไรก็ได้ · รุ่นนี้มี **มือเปล่า (หมัด)** และ **คาตานะ**
- **มาตรวัดการกลืนกิน** — ตีหนักดึงพลังผลึกมาใช้ ยิ่งใช้มากยิ่งถูกผลึกกลืน
- **โซนดิน** เล่นได้ครบทั้งโซน พร้อมบอสสองเฟส · ศัตรูทุกตัวมีท่าเงื้อให้อ่านก่อนโจมตี
- **ผลึกตกจากศัตรู** — เดินเข้าไปเก็บในฉาก เล่นหลายคนใครเก็บก่อนได้ก่อน
- **เล่นออนไลน์ด้วยกัน** — เปิดห้อง/เข้าห้อง แชทในห้อง เข้าด่านพร้อมกัน · เน็ตหลุดแล้วต่อกลับเองอัตโนมัติ
- **ล็อบบี้** — ร้านค้า · อุปกรณ์ · เควส · คลัง · แลกเปลี่ยน · เพื่อน
- **บัญชีของเกมเอง** — สมัครในเกม เข้าได้ทีละเครื่อง
- **อัปเดตตัวเองได้** — มีรุ่นใหม่ เกมโหลดและติดตั้งให้เองตอนเปิดเกม
- **ภาษาไทย / อังกฤษ** · ตั้งค่าภาพ เสียง การควบคุม · รองรับจอย

### ปุ่มควบคุม
`◀ ▶` เดิน (เคาะสองครั้ง = วิ่ง) · `▲` กระโดด · `Z` ตีเบา · `X` ตีหนัก · `C` บล็อก/แพร์รี · `Shift` dash · `Q W E R` ไอเทม
จอย: RB เบา · RT หนัก · LB บล็อก · B dash · A กระโดด

### วิธีติดตั้ง
1. โหลด `CalamityVein-1.0.0-windows.zip` (Windows) หรือ `CalamityVein-1.0.0-mac.zip` (macOS) ด้านล่าง
2. แตกไฟล์ไว้ในโฟลเดอร์ที่เขียนได้ (เช่น `เอกสาร` หรือ `D:\Games`) — ไม่แนะนำ `Program Files` (เกมอัปเดตตัวเองไม่ได้)
3. เปิดเกมแล้วสมัครบัญชีในเกม

### รู้ไว้ก่อนเล่น

## 🇬🇧 English — Beta

**Calamity Vein** is a 1–6 player co-op side-scrolling action game set after a calamity, where crystals are technology — and every use of power has a price.

### What's in this release
- **Timing-based combat** — chain light attacks, finish with a heavy · block to reduce damage · block at the right moment to parry: no damage, and enemies lose their footing until they fall · dash to evade
- **No classes** — pick 1 of 4 character looks and wield any weapon · this release has **bare fists** and the **katana**
- **Devour gauge** — heavy attacks draw on crystal power; the more you use, the more the crystal consumes you
- **Earth zone** fully playable, with a two-phase boss · every enemy attack has a readable wind-up
- **Crystal drops** — walk over them to collect; in co-op, first come first served
- **Online co-op** — open/join rooms, room chat, synchronized stage start · automatic reconnect
- **Lobby** — shop · equipment · quests · storage · trading · friends
- **Game account** — sign up in game, one device at a time
- **Self-updating** — new versions download and install themselves when you start the game
- **Thai / English** · graphics, audio and control settings · gamepad support

### Controls
`◀ ▶` move (double-tap = run) · `▲` jump · `Z` light · `X` heavy · `C` block/parry · `Shift` dash · `Q W E R` items
Gamepad: RB light · RT heavy · LB block · B dash · A jump

### Install
1. Download `CalamityVein-1.0.0-windows.zip` (Windows) or `CalamityVein-1.0.0-mac.zip` (macOS) below
2. Extract to a writable folder (e.g. `Documents` or `D:\Games`) — avoid `Program Files` (the game can't update itself there)
3. Start the game and sign up in game

### Notes
- **All 1.x releases are beta** — expect bugs and unfinished parts · character models are placeholders · report issues at calamityvein.com
- Windows may show "Windows protected your PC" because the file isn't signed yet → click **More info → Run anyway**
- macOS may refuse to open an app from an unidentified developer → right-click the game → **Open**

# Calamity Vein v1.0.0 (Beta) — ผลึกวิบัติ รุ่นเบต้าแรก

## 🇹🇭 ภาษาไทย — รุ่นเบต้า

**Calamity Vein — ผลึกวิบัติ** เกมแอ็กชันเลื่อนข้างแบบร่วมทีม 1–6 คน ในโลกหลังภัยพิบัติที่ผลึกคือเทคโนโลยี และทุกครั้งที่ใช้พลังต้องจ่ายราคา

### มีอะไรในรุ่นนี้
- **4 อาชีพ** — หมัด · ดาบ · สมุดธาตุ · คฑาเวท พร้อมสกิลชุดแรกครบทุกอาชีพ และต้นไม้สกิลให้เลือกลงแต้มเอง
- **มาตรวัดการกลืนกิน** — ยิ่งใช้พลังมาก ยิ่งแรง แต่ร่างกายก็ยิ่งถูกผลึกกลืน
- **โซนดิน** เล่นได้ครบทั้งโซน พร้อมบอสสองเฟส
- **เล่นออนไลน์ด้วยกัน** — เปิดห้อง/เข้าห้อง แชทในห้อง เข้าด่านพร้อมกัน เห็นความคืบหน้าการโหลดของเพื่อน · เน็ตหลุดแล้วต่อกลับเองอัตโนมัติ
- **ล็อบบี้** — ร้านค้า · อุปกรณ์ · เควส · คลัง · แลกเปลี่ยน · เพื่อน
- **บัญชีของเกมเอง** — สมัครในเกม เข้าได้ทีละเครื่อง
- **อัปเดตตัวเองได้** — มีรุ่นใหม่ เกมโหลดและติดตั้งให้เองตอนเปิดเกม ไม่ต้องโหลดใหม่ทั้งก้อน
- **ภาษาไทย / อังกฤษ** · ตั้งค่าภาพ เสียง การควบคุม · รองรับจอยในด่าน

### วิธีติดตั้ง
1. โหลด `CalamityVein-1.0.0-windows.zip` (Windows) หรือ `CalamityVein-1.0.0-mac.zip` (macOS) ด้านล่าง
2. แตกไฟล์ไว้ในโฟลเดอร์ที่เขียนได้ (เช่น `เอกสาร` หรือ `D:\Games`) — ไม่แนะนำ `Program Files` (เกมอัปเดตตัวเองไม่ได้)
3. เปิดเกมแล้วสมัครบัญชีในเกม

### รู้ไว้ก่อนเล่น
- **รุ่น 1.x ทั้งหมดเป็นเบต้า** — เน้นพัฒนาระบบ ยังมีบั๊กและของที่ยังไม่เสร็จ · รุ่นจริงคือ 2.0.0 · แจ้งปัญหาได้ที่ calamityvein.com
- Windows อาจขึ้นหน้าเตือน "Windows protected your PC" เพราะไฟล์ยังไม่ได้เซ็น → กด **More info → Run anyway**
- macOS อาจขึ้นว่าเปิดไม่ได้เพราะไม่รู้จักผู้พัฒนา → คลิกขวาที่เกม → **Open**

## 🇬🇧 English — Beta

**Calamity Vein** is a 1–6 player co-op side-scrolling action game set after a calamity, where crystals are technology — and every use of power has a price.

### What's in this release
- **4 classes** — Fist · Sword · Element Tome · Arcane Staff, each with its first full skill set and a skill tree
- **Devour gauge** — the more power you use, the stronger you get, and the more the crystal consumes you
- **Earth zone** fully playable, with a two-phase boss
- **Online co-op** — open/join rooms, room chat, synchronized stage start with party loading progress, automatic reconnect
- **Lobby** — shop · equipment · quests · storage · trading · friends
- **Game account** — sign up in game, one device at a time
- **Self-updating** — new versions download and install themselves when you start the game
- **Thai / English** · graphics, audio and control settings · gamepad support in stages

### Install
1. Download `CalamityVein-1.0.0-windows.zip` (Windows) or `CalamityVein-1.0.0-mac.zip` (macOS) below
2. Extract to a writable folder (e.g. `Documents` or `D:\Games`) — avoid `Program Files` (the game can't update itself there)
3. Start the game and sign up in game

### Notes
- **All 1.x releases are beta** — focused on building the systems; expect bugs and unfinished parts · the full release is 2.0.0 · report issues at calamityvein.com
- Windows may show "Windows protected your PC" because the file isn't signed yet → click **More info → Run anyway**
- macOS may refuse to open an app from an unidentified developer → right-click the game → **Open**
